## 3.7 Data Collection and Preparation

RouterBench and LLMRouterBench will be the candidate sources of already-scored outputs (Hu et al., 2024; H. Li et al., 2026). The team will inspect task identifiers, prompts, model revisions, scores, token counts and cost fields before choosing a shared evaluation subset. LongMemEval will remain in Appendix B for licence tracking only while router-managed context and memory experiments remain unresolved earlier proposals.

| Data stage | Planned control |
|---|---|
| Provenance | Record official release, revision, file hashes, model IDs, prompting settings and label definitions. |
| Coverage | Verify aligned per-request outcomes for [PLACEHOLDER: model names], spanning a small/cheap, mid-tier and frontier option. |
| Licence | Check dataset and component terms separately from repository code licences; see Appendix B. |
| Cleaning | Detect duplicate/near-duplicate prompts, invalid scores, missing outcomes and inconsistent token/cost units. |
| Split | TODO: split protocol and proportions; group related requests and prevent duplicate leakage. |
| Features | Fit classification, retrieval index, normalisers and calibration only on the permitted training/validation partitions. |
| Evaluation | Keep evaluated outcomes out of training and retrieval for those evaluated requests; labels will be revealed only for scoring. |

The exact estimator, labels, calibration method and split protocol will remain TODO. A dataset's example split will not automatically become the study protocol. A tuning pilot will be separated from the untouched test partition. If cross-model aligned outcomes are unavailable, the limitation will be recorded rather than filling gaps with unrelated benchmark averages.

No raw benchmark data will be redistributed in the proposal repository. RouterBench has an MIT code licence but a dataset-level redistribution grant was not established by the inspected card. LLMRouterBench's MIT badge will not resolve the missing licence text/data card. LongMemEval's MIT repository licence will be recorded with its notice requirements, with downloaded packaging and third-party terms checked before sharing. Actual dataset-use clearance will remain TODO where terms are unresolved.

New hosted calls will be restricted to a capped pilot/subset under [PLACEHOLDER: hosted-call spending cap]. Local models will support reliability tests. A quantised local deployment and a historical hosted deployment of a similarly named model will be treated as distinct configurations. The index will not assume they share quality labels. No API calls will be commissioned by this drafting task.
