## 2.3 Enabling Technologies and Techniques

A fixed rule is inexpensive and interpretable but cannot learn model-specific performance from outcomes. A trained classifier uses labelled examples, while retrieval estimates performance from similar prior requests; RouterDC and ContextualRouter illustrate these alternatives (S. Chen et al., 2024; Varangot-Reille et al., 2026). RouterDC reports a 1.90% out-of-distribution improvement, while ContextualRouter finds simple nearest-neighbour estimation competitive across five benchmarks. Different datasets prevent direct comparison of these figures. Their dependence on training or retrieval coverage motivates testing each component and its combination against fixed and rule-based baselines.

A gateway can apply request validation, capability filtering and budget accounting independently of how suitability is estimated. This separation matters because neither a task label nor a similarity score establishes that a candidate supports the required format or context length. Price, latency and quality estimates should be versioned and evaluated against observed outcomes, with all attempts included in cost. A deterministic feasibility filter and constrained selector are therefore proposed rather than treating every requirement as an unrestricted weighted score.

The execution layer has different design trade-offs. MuxServe reports up to 1.8-fold throughput or 2.9 times as many requests within 99% service-level attainment under its tested workloads (Duan et al., 2024); SGLang reports up to 6.4-fold throughput in the evaluated workloads in the cited preprint (Zheng et al., 2024). AlpaServe addresses model placement and statistical multiplexing (Z. Li et al., 2023), while S-LoRA multiplexes adapters sharing a base model (Sheng et al., 2024). These serving optimisations require controls and deployment assumptions that differ from choosing between independent hosted and local models. The project will use an existing backend where feasible and report its configuration instead of treating engine acceleration as a routing result.
