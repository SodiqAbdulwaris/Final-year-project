# Style and assembly guide

The supplied template structure in the owner's task will govern assembly. The Word template is not present in this checkout; no original DOCX will be edited. Archived template observations are retained in source-facts.md, but the owner's explicit structure takes precedence.

| Item | Submission setting |
|---|---|
| Page | A4 |
| Margins | Top, bottom and right 2.5 cm; left 4 cm |
| Body | Times New Roman, 12 pt; 1.5 line spacing and justified text per historical template notes |
| Tense | Future for proposed activities; switch to past in the final report after work is performed |
| Headings | Apply Word Heading styles matching the numbered sections |
| Captions | Use Word's Insert Caption tool; regenerate lists and cross-references after rendering diagrams |
| Citations | APA 7 author–date; DOI as https://doi.org/... where assigned; distinguish preprint DOI from proceedings DOI |
| Abbreviations | Spell out at first use; maintain an alphabetical list |
| Guidance | Remove metadata headers and Notes for the team before pasting; omit coloured italic template instructions |

Existing literature will be described in the tense appropriate to published work; future tense applies to this project's activities. Past ethics/AI assistance statements will describe only work already done. A proposal abstract will describe expected outputs without claiming results.

Every active file will begin with Status, Depends on, Sources and Open items. DRAFT means written but not approved; TODO means content awaits work; NEEDS-DECISION means an unresolved choice changes the content; VERIFIED describes a checked item with stated scope, never an unqualified claim that an entire chapter is correct.

Unknown facts will remain [PLACEHOLDER: description], TODO or [PROVISIONAL: revise after pilot]. Personal placeholders will use the owner's exact bracketed labels. Targets will not be imported from illustrative examples or old drafts. Submission page counts will be assessed after Word layout: Chapter 1 6–10 pages; Chapter 2 15–25 pages. Markdown word counts do not prove page compliance.
