# Declaration on the Use of Generative AI Tools

Generative AI tools were used in preparing this proposal. The tools, the tasks, the sections affected and the way each output was checked are listed below. The team remains responsible for the accuracy, attribution and final wording of the submission, and AI output was not treated as a primary academic source.

| Tool and version | Task it was used for | Chapter / section | How the output was verified or edited |
|---|---|---|---|
| Claude Code (Claude Sonnet 5.5) | Drafting and editing text for the abstract and Chapters 1 to 3; assembling the Word document; checking selected facts and citations against source documents (Stanford AI Index 2025, the Nigeria Data Protection Act, 2023, the African Economic Outlook 2026 and a National AI Strategy summary). | Abstract; Chapters 1 to 3; references; appendix list; this repository update | Selected figures and legal sections were compared with the source text. Claims that could not be checked were removed or labelled. The team still has to read the text and verify the remaining citations. |
| Claude Code (earlier version not recorded) | Earlier literature searches, paper summaries and draft material kept in the project repository. | Chapter 2 and the repository literature folders | Sampled fact-checks are recorded in the repository (limitations, L07); key papers still have to be read directly by the team. |
| OpenAI Codex (model not recorded) | Earlier reconciliation of the design, Markdown drafting, bibliography and claim checks. | Repository drafts of Chapters 1 to 3 and the appendices | Scoped checks against primary sources; no Word rendering or experiments were run. |
| OpenAI Codex CLI 0.159.3 (image generation) | Drawing the figures from the team’s written design descriptions. | Figure 2.1 and Figures 3.1 to 3.11 | Each image was compared with its description and regenerated where arrows or labels were wrong. The team has yet to review the final images. |

The full use and verification log is kept in Appendix H (repository file 07-appendices/E-genai-use-log.md). The team will read the key cited sources directly and will not imply personal reading of any source that was only read through automated tools. Each member signs below to confirm this declaration.
