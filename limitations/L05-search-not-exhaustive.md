# L05: The literature search is not exhaustive

**Limitation.** The reading list was a seed list; workers added papers by web, arXiv and publisher searches. The arXiv API, Semantic Scholar, dblp and OpenReview were often rate-limited or blocked; Google Scholar was not run. Search logs in each topic overview record strings, dates and counts but cannot be called systematic-review quality.

**Effect.** Table 2.1 (search strategy) is honest but modest; relevant papers may be missing, especially 2026 preprints.

**What to do.** Run one extra search per topic yourself (Google Scholar, ACM, IEEE) and add finds; describe the method as a structured, not systematic, review.
